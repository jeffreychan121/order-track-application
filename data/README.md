# 本地输入数据

- `orders.json` 保存题目提供的订单、商品数量、收件信息及追踪分组，不包含任何计算结果。
- `products.json` 保存应用读取的规范化商品目录；`source/sku-query-result.json` 保存查询页返回的完整原始 JSON，便于追溯。

本次查询使用 `product_list` 表并按订单中的 SKU 过滤；返回的 9 条记录与订单中的 9 个不同 SKU 完全匹配。商品字段来自查询结果，不是估算数据。RRP 以 AUD 计且含 GST；价格以十进制字符串保存，重量和尺寸保留原始数值及单位（例如 `68.0 g`、`76.0 mm`）。

货币公式将在后续阶段由后端动态计算，不能把派生金额存入这些源输入文件。新增订单和 SKU 时保持相同字段结构即可。

承运商凭据不属于本目录输入数据；凭据只放在项目根目录本地 `.env`，不得进入订单、商品 JSON 或前端。
